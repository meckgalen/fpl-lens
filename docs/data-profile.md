## 1. File presence & detected character encoding

Encoding is what `chardet` actually detected from the bytes, not assumed.
`teams.csv` is not published upstream for the three earliest seasons.

**Caveat:** `chardet` is a statistical guess. Where a cell reads e.g.
`ISO-8859-1` but the file has **no** non-ASCII bytes (`non-ASCII? = no`), that
label is moot — the file is pure ASCII and decodes identically as UTF-8. Only
files flagged `non-ASCII? = yes` actually require the detected encoding at
ingest, so those are the only rows worth trusting the label on.
